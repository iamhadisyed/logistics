# GoDaddy Deployment (Dakia)

Use this folder to prepare and upload Dakia on GoDaddy shared hosting (no Node runtime).

## Included

- `backend/` -> Laravel backend package for GoDaddy
- `frontend/` -> static frontend upload target
- `prepare-frontend-static.ps1` -> builds and copies frontend static files
- `GO_LIVE_GUIDE.md` -> full go-live instructions

## Quick start

1. Open and follow `GO_LIVE_GUIDE.md` only.
2. Complete checklists A through G.
3. On every future deployment, update:
   - `Last Updated`
   - `Deployment Log`
